# Nexus 地圖記錄與未載入目的地修正方案

## Why

使用者要求先檢查四個問題並提出方案：地圖資料歸屬、手持玩家標記、擴張後新區域細節，以及未載入磁石被判成失效。本提案以本機 `916106b`（0.3.22）為基準；只做原始碼與歷史診斷，未宣稱在使用者伺服器重現。

## What Changes

- 明確以 MapId 持有地形與細節記錄，統一正式入口和替代入口的地圖授權規則，保留個人的指南針探索、最愛與權限。
- 手持地圖使用原版 MapRenderer 的暫態玩家圖示；不將持有者座標寫進共用地圖。
- 新增按需採集的細節分頁，擴張後新探索範圍也能有 1 方塊／像素的資料；原有祖先地圖繼續作為歷史來源。
- 將目的地「未載入」與「實際失效」分開；恢復既有非同步載入與安全落點流程，載入後重驗結構、權限、報價。
- 加入版本化、可回復的資料遷移與固定回歸測試，納入既有 Build workflow。

## Impact

主要修改限於 TotemNexus。Observer 正式 Screen 的細節呈現需同步更新 Nexus 自有 provider 並驗證 TotemObserver；死亡節點需驗證 Remnant 相容。Core 共用 API 不預設修改。詳見 [design.md](design.md) 與 [tasks.md](tasks.md)。

本提案供使用者先看設計；尚未修改遊戲程式、存檔或發布內容。
